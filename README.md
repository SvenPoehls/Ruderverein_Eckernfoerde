# Ruderclub Eckernförde – Webseiten-Entwurf

Reines HTML/CSS/JS, kein Build nötig. `index.html` im Browser öffnen oder den Ordner auf einen beliebigen Webspace / Netlify hochladen.

- `css/style.css` – Design; Farben und Schriften zentral in `:root`
- `js/main.js` – Menü, Neuigkeiten-Anzeige
- `js/news-data.js` – **Beiträge für „Aktuelles“** (Block kopieren, Text/Datum anpassen, Bild in `assets/img/news/` ablegen)
- `assets/fonts/` – optional lokale Schriften (woff2) für datenschutzkonformes Hosting

Platzhalter finden: nach `PLATZHALTER` und `MUSTERTEXT` suchen (gelb markiert auf der Seite).
Später denkbar: Decap CMS o. ä., damit der Verein Beiträge per Browser-Formular pflegt statt per Datei.
